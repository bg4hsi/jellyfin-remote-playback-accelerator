# 项目定位

## Jellyfin 远程播放加速器

本项目不是 CDN，也不是传统意义上的边缘计算平台。

它针对家庭 NAS 运行 Jellyfin 时，公网远程播放体验不稳定的问题，通过 VPS 公网节点、反向隧道和 HLS 分片预取机制优化传输路径。

核心目标：

- 降低家庭宽带持续上传压力；
- 提高远程播放稳定性；
- 减少起播等待和拖动缓冲；
- 充分利用 VPS 的公网带宽和缓存能力。

## 典型应用场景

家庭环境：

```
NAS + Jellyfin
        |
        |
 家庭宽带上传
```

远程访问：

```
播放器
   |
   v
VPS 公网节点
   |
   v
家庭 NAS
```

## 核心思想

不是提升家庭宽带本身速度，而是改变远程访问路径：

1. VPS 作为公网入口；
2. 播放请求经过 VPS；
3. Worker 根据播放进度提前获取 HLS 分片；
4. 后续播放优先使用 VPS 已缓存内容。

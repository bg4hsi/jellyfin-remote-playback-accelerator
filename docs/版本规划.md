# Jellyfin 远程播放加速器版本规划

## v18.4 缓存可靠性版

当前版本重点：

- 监控 Jellyfin 播放 Session；
- 识别转码 hash 变化；
- 预取成功后确认 nginx 返回 HIT；
- 缓存丢失后优先修复播放窗口；
- NAS 转码结束后分批同步到 `last_generated`；
- 支持 LIVE、DRAIN、HOLD 状态。

## 后续计划

### v18.5 播放结束清理

目标：

- 识别播放器真正关闭；
- 暂停播放时保留缓存；
- 关闭播放后释放对应缓存资源。

> 不得仅根据 NAS `active=false` 清空缓存；这表示转码完成，不表示播放结束。

### v19 多用户支持

目标：

- 多个同时播放 Session；
- 每个用户独立状态管理；
- 独立缓存生命周期。

### v20 可视化管理

计划：

- 当前播放状态查看；
- 缓存命中率统计；
- 预取进度展示；
- 网络性能分析。

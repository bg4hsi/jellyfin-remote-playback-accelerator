# Jellyfin 远程播放加速器安装指南

## 系统组成

本项目由三部分组成：

1. 家庭端
   - Jellyfin / NAS
   - 分片辅助服务
   - SSH 反向隧道客户端

2. VPS 端
   - Nginx 播放入口
   - HLS 缓存
   - 预取 Worker
   - 状态管理服务

3. 播放端
   - Jellyfin 官方客户端或兼容 HLS 播放器

## 安装流程

### 1. 建立家庭端到 VPS 的反向连接

家庭端主动连接 VPS，避免家庭网络入站限制。

示例：

```
家庭 NAS ---- SSH 反向隧道 ---- VPS
```

### 2. 配置 VPS Nginx

需要配置：

- 播放代理
- HLS segment 缓存
- 内部预取入口

### 3. 启动 Worker

Worker 根据当前播放状态：

- 预取未来分片；
- 监控转码状态；
- 转码完成后继续同步已生成分片。

## 注意

首次部署建议先测试单个用户、单个播放流。

多用户、多项目需要扩展 session 管理逻辑。

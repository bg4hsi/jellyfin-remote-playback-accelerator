# 为什么使用 TCP 443 反向隧道

## 背景

本项目来自家庭宽带远程 Jellyfin 使用场景。

部分家庭宽带环境中可能出现：

- 下载速度正常；
- Speedtest 结果正常；
- 但是公网服务上传吞吐不稳定。

在实际测试环境中，TCP 443 隧道连接表现更加稳定，因此采用家庭端主动连接 VPS 的方式。

## 为什么不是直接访问家庭 NAS

家庭网络通常存在：

- NAT；
- 动态地址；
- 入站连接限制；
- 运营商网络策略影响。

因此采用：

```
家庭 NAS
   |
   | 主动连接
   | TCP 443
   v
VPS
```

而不是：

```
公网用户
   |
   v
家庭 NAS
```

## 443 的作用

443 在这里只是反向隧道的传输端口，用于建立稳定的家庭端到 VPS 的连接。

它不是为了绕过认证、安全控制或访问限制。

实际效果取决于：

- 所在地区；
- 运营商网络策略；
- 使用时间；
- 网络质量。

建议用户在自己的网络环境中测试不同端口表现。

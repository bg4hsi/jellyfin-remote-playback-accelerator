# Jellyfin 远程播放加速器配置说明

## 核心参数

### 预取窗口

控制 Worker 一次提前同步多少 HLS 分片。

窗口过小：

- 容易追上播放器；
- 卡顿风险增加。

窗口过大：

- 占用 VPS 存储；
- 增加家庭上传压力。

## Session 管理

系统通过以下信息识别播放会话：

- 播放路径 prefix；
- Jellyfin 转码 hash；
- HLS 生成进度。

当 hash 变化时：

1. 停止旧 session；
2. 创建新 session；
3. 重新进行预取。

## 缓存策略

流程：

```
播放开始
  ↓
预热缓存
  ↓
实时预取
  ↓
转码完成后继续同步
  ↓
保持缓存
```

## 建议

VPS 存储空间应根据影片码率和同时播放数量规划。
